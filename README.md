# portavan
portavan AI Model: From Training to Development and Coding
The goal of this project is to build a model from scratch and prepare its data.
Please take a look at the [License](https://github.com/invincible627/portavan?tab=License-1-ov-file) before doing anything.
## Available Languages
Persian and English
### Important Notes
If you would like to contribute to this project, please take a look at the [Contribution Guide](contributing.md).
Due to the project's need for diverse data from contributors with varying levels of access, a Telegram group has been established for this project. Individuals who are not familiar with GitHub may submit their data through the [Telegram group](https://t.me/portavan_0627) or via the [management account](https://t.me/red_heart_00). Submitted data will be reviewed and, upon approval, added to the main project repository. The contributor's name, along with the number of dialogues and suggested topics, will be recorded in the contributors file.
Compliance with the project rules is mandatory for all contributors, regardless of the method of data submission. The rules have been posted in the Telegram group, and the contribution guide will also be made available separately within the group.
Please note that data varies because humans have different moods and personalities. And our moods and personalities require different types of data. From bored dialogues to informal ones, so please, if you are working on a topic, consider these rules and differences in that topic, but avoid using offensive language.
Another note is that the person who founded this project is also a beginner in this field, and this project is a space for learning and being constructive.

توجه داشته باشید، داده‌ها متفاوت هستند، زیرا ما انسان‌ها خلق و خوی متفاوتی داریم. و خلق‌و‌خوی ما انسان‌ها، داده‌های متفاوتی را می‌طلبد.
